# 図解でわかるVisual Studio Code徹底入門 練習用のファイル

書籍『図解でわかるVisual Studio Code徹底入門 インストールからGit・GitHub Copilotまで実務で使える操作』（早瀬 透）の練習用のファイルです。

本では、自己紹介の Web ページ（ポートフォリオ）を1冊を通して作りながら、VS Code の使い方を覚えます。
このページには、**各章の始まりの状態のポートフォリオ**と、本文で長い文をコピーして使うファイルが入っています。

- 本文の例を打つ代わりに、ここからコピーして貼り付ける
- 途中の章から読み始めるとき、その章の始まりの状態をそろえる
- 自分のファイルがうまく動かないとき、本のとおりのファイルと見比べる

といった使い方をしてください。

## ファイルを入手する方法

やりたいことに合わせて、2つの方法から選んでください。

| やりたいこと | 方法 |
|---|---|
| 1つのファイルの中身をコピーしたい・見比べたい | 下の表の章のフォルダーを押し、ファイル名を押してブラウザーで開く。中身の右上の、四角が2つ重なったボタン（Copy raw file）でコピーできます |
| 全部の章のファイルを手元に置きたい | このページの緑の［Code］を押し、［Download ZIP］を押す（下の「ZIP でまとめてダウンロードする方法」） |

### ZIP でまとめてダウンロードする方法

1. このページの上の緑の［Code］を押し、［Download ZIP］を押します
2. 「ダウンロード」フォルダーに `vscode-kyokasho-samples-main.zip` が入ります
   - Windows: ファイルを右クリックして［すべて展開］を選び、出てきた窓の［展開］を押します
   - Mac: ファイルをダブルクリックします
3. 「ダウンロード」フォルダーに `vscode-kyokasho-samples-main` フォルダーができます。その中の `ch02`〜`ch14` が章ごとのフォルダーです。Windows では、同じ名前のフォルダーがもう1つ中にあり、章ごとのフォルダーはその内側にあります

ファイルを開くときは、ファイルの窓（Windows のエクスプローラー、Mac の Finder）でダブルクリックせず、VS Code の［ファイル］メニューの［ファイルを開く...］（Mac は［開く...］）から開きます。HTML のファイルをダブルクリックすると、VS Code ではなくブラウザーで開いてしまうためです。

## 途中の章から始めるとき

その章のフォルダーの中身を全部、エクスプローラー（Mac は Finder）で自分の `portfolio` フォルダーにコピーします。

第10章からは、Git の記録（コミット）を使います。フォルダーの中身を写したときは、第10章のやり方で記録を始めてください。
