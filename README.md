# 練習用のファイル

『図解でわかるVisual Studio Code徹底入門 インストールからGit・GitHub Copilotまで実務で使える操作』で使う練習用のファイルです。

## 入手のしかた

このページの緑の［Code］を押し、［Download ZIP］を押すと、まとめて入手できます。

## 中身

章ごとのフォルダーに、その章の始まりの状態のポートフォリオが入っています。途中の章から始めるときは、そのフォルダーの中身を、自分の portfolio フォルダーに写します。

| フォルダー | 使う章 |
| --- | --- |
| ch02〜ch05 | 第2章〜第5章（第2章は、本文で書く `index.html` などのもと） |
| ch06 | 第6章　Markdown（`README.md` のもと） |
| ch07 | 第7章　Web ページとデバッグ（わざと間違いを入れたファイル） |
| ch08 | 第8章　ターミナルとタスク（`.vscode/tasks.json`） |
| ch09 | 第9章　Python（`update_date.py`） |
| ch10〜ch14 | 第10章〜第14章の始まりの状態 |
| ch13・ch14 | AI に頼む文（`頼む文.txt`）と、決まりのファイル（`ch14/コピー用/AGENTS.md`） |

第10章からは Git の記録（コミット）を使います。フォルダーを写したときは、第10章のやり方で記録を始めてください。

本文と練習用のファイルに出てくる名前やメールアドレスは、すべて仮の値です。
